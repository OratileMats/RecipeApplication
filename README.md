# 🧑‍🍳 Recipe Manager (C# Console App) (In the works, minor changes to be made to the code for it to run perfectly)

A simple **C# Console Application** built using the **.NET Framework** that allows users to manage recipes.  
You can add ingredients, view your recipe, scale ingredient quantities, reset values, or clear everything — all from the command line!

---

## 📋 Features

When you run the program, you’ll be presented with the following menu:

Enter 1 to enter recipe details
Enter 2 to display recipe
Enter 3 to scale recipe
Enter 4 to reset quantities
Enter 5 to clear recipe
Enter 6 to exit

### ✨ Description of Options
| Option | Description |
|---------|-------------|
| **1. Enter recipe details** | Allows the user to input the recipe name, number of ingredients, and details for each ingredient (name, quantity, and unit). |
| **2. Display recipe** | Displays the complete recipe including ingredient names, quantities, and steps (if applicable). |
| **3. Scale recipe** | Multiplies all ingredient quantities by a user-selected factor (e.g., 0.5, 2, or 3). |
| **4. Reset quantities** | Restores ingredient quantities to their original values before scaling. |
| **5. Clear recipe** | Deletes all recipe details from memory so you can start fresh. |
| **6. Exit** | Closes the program. |
